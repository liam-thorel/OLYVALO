# Revue VALORANT — 2 septembre 2026

## Patch du jeu et sources

- Jeu : **13.05**, publié le 1er septembre. [Notes officielles Riot](https://playvalorant.com/fr-fr/news/game-updates/valorant-patch-notes-13-05/).
- Ce patch corrige principalement des bugs. Aucune nouvelle rotation de cartes ni modification majeure d'équilibrage n'est annoncée.
- Rotation conservée : Haven, Abyss, Lotus, Split, Ascent, Sunset, Summit.
- Le champ `comp.patch` indique le patch auquel la recommandation a été revue. Il ne représente pas le patch de la rencontre professionnelle.
- `teamPresets[].patch` conserve le patch réellement joué, affiché avec la date et le score dans Maps.
- Les recommandations ranked et leurs échantillons MetaBot sont conservés, explicitement étiquetés **données 13.04** : ce ne sont pas de nouvelles statistiques 13.05.
- Fun : défis inchangés. Trois catégories par carte : ranked, pro, fun.
